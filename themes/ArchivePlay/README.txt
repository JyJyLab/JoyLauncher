ARCHIVE / PLAY — Joy Launcher 1.1.0 이상

1. 설치
1) ArchivePlay 폴더를 SD 카드 /JoyLauncher/themes/ 에 복사.
2) Y 옵션 > 테마 설정 > 아카이브 플레이 선택.
3) 옵션 > 화면 효과를 켜야 애니메이션이 동작합니다.

2. 테마 빌더
1) 파일 > 열기 > 다른 곳의 테마 폴더 가져오기에서 theme.txt 선택.
2) F5로 데모 실행. 키보드 방향키, Enter=A, Esc=B, T=X, Y=Y, Q/W=L/R, Z/X=ZL/ZR, F=즐겨찾기.

3. 구성
1) 메인: 가로 캐러셀, 220ms 이동.
2) 게임: 텍스트 목록 14행, 선택 박스 180ms 이동.
3) 화면 전환: 220ms 페이드.
4) 게임 이미지와 박스아트는 사용 중인 롬 자료를 불러옵니다. 롬 및 게임 이미지는 포함하지 않았습니다.
5) 긴 제목은 선택 상태의 스크롤로 확인합니다.

4. 검증 범위
1) 레이아웃 문법, 14행 높이, 참조 파일 존재, ZIP 무결성 확인.
2) Windows JoyDemo 1.1.0-test4 실제 렌더링 캡처 확인. Switch 실기 미검증.
3) ZIP의 Captures 폴더는 JoyDemo가 직접 저장한 실제 렌더링 캡처입니다. 게임 자료는 사용자의 ES-DE 이미지로 별도 미리보기 자료를 구성했습니다.
4) 주요 기종 카드는 승인 시안을 참조해 재생성했습니다. 이미지 재생성 특성상 시안과 픽셀 단위로 동일하지는 않습니다. 내장 기종 분류 전체를 같은 스타일의 새 카드로 교체했습니다.

5. 출처
1) 기종 카드는 승인 시안을 기준으로 생성한 이미지입니다. 기기 외형 및 로고의 세부 표현은 실제 제품과 차이가 있을 수 있습니다.
2) Noto Sans KR: SIL OFL. Nimbus Sans: URW, 번들 라이선스 참조.
3) 배경, 레이아웃, 선택 표시: Archive / Play 제작.

6. 아이콘 전체 구성
1) 내장 기종 분류 70개에 대응하는 파일은 ICON_INVENTORY.json 참조.
2) 즐겨찾기 및 홈브류 즐겨찾기도 새 아이보리 카드로 교체.
3) 새 아이콘이 나타나지 않으면 테마를 다시 선택해 캐시를 갱신하세요.
