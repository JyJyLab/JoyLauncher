## Joy Launcher v0.7.2

### 수정
- 업데이트 설치 시 "런처는 업데이트했지만 기본 홈브루 메뉴(/hbmenu.nro) 교체에 실패" 오류 수정.
  실행 중인 런처 파일이 내장 데이터(romfs) 때문에 열려 있어 교체되지 않던 문제로, 교체 전에 내장 데이터를 닫도록 했습니다.
  (앨범/기본 홈브루 메뉴로 실행한 경우와 `/switch/joylauncher` 에서 직접 실행한 경우 모두 해당)
- 이름 바꾸기가 안 되는 경우 내용 복사로 교체하는 대비 처리 추가.

### 0.7.1 에서 업데이트할 때
0.7.1 의 업데이트 기능에 위 문제가 있어, 기본 홈브루 메뉴로 실행 중이면 같은 오류가 날 수 있습니다.
그때는 런처 본체는 이미 0.7.2 로 바뀌어 있으므로 **Y 옵션 → "기본 홈브루 메뉴를 Joy Launcher 로 업데이트"** 를 한 번 실행하면 됩니다.
