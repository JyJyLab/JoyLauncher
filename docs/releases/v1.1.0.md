## Joy Launcher v1.1.0

### 새 기능
- **테마 빌더 (PC 프로그램)**: PC 에서 **스위치 화면 그대로** 보며 테마를 만드는 **Joy Theme Builder** 를 함께 배포합니다. 미리보기는 런처의 화면 그리기 코드를 그대로 씁니다.
  - 윈도우 10·11 64비트: `JoyThemeBuilder_win64_1.1.0.zip` (`JoyThemeBuilder.exe`, 데모 창 `JoyDemo.exe`)
  - 리눅스 x86_64: `JoyThemeBuilder_linux_x86_64_1.1.0.tar.gz` (`./joythemebuilder`, `sudo apt install libsdl2-2.0-0 libsdl2-image-2.0-0 libsdl2-ttf-2.0-0` 필요)
  - 시작 마법사(스타일 고르기 → 자동 매칭 / 빈 테마), 요소 넣기, 디자인 패널, 세트별 그림 라이브러리, 나만의 카테고리 편집, F5 데모 창, 패드 조작
  - **스위치로 보내기 (FTP)**: sys-ftpd·ftpd 또는 런처의 "PC에서 테마 받기" 화면으로 보내기, 스위치에 있는 테마 목록 보기·지우기. zip·폴더 내보내기
  - 사용법: `테마_빌더.md`
- **레트로게임갤러리테마** (`themes/DcGall`) 추가 — 함께 들어 있는 테마가 4종이 되었습니다. 갤러리 카드 + 번호·제목·조회수 게시판 표, 흰색·남색 디자인. 글꼴 Noto Sans KR (SIL OFL 1.1), 아이콘 ES-DE Canvas (Siddy212, CC0). "dcinside" 글자는 패러디 표기이며 디시인사이드와 관계없습니다. 런처 v1.1.0 이상 필요.
- **테마 한 번에 받기**: 테마 선택 창의 팩별 내려받기 줄을 **"기본 테마 4종 내려받기"** (모두 있으면 "기본 테마 4종 다시 받기 (최신으로)") 한 줄로 합쳤습니다. 최신 릴리스에서 4종을 차례로 받습니다. (B 로 취소)
- **PC에서 테마 받기 (FTP)**: Y 옵션(테마 설정 바로 아래) 또는 테마 선택 창 맨 아래 줄. 화면에 나온 `ftp://<스위치 IP>:<포트>`(보통 5000) 로 PC 에서 보냅니다. 사용자·비밀번호 비움. 그 화면이 열린 동안만 열리며 `/JoyLauncher/themes/…`, `categories.txt`, `categories/…` 만 쓰고 지울 수 있습니다. B 로 닫으면 테마를 다시 읽습니다.
- **테마 지우기**: 테마 선택 창에서 테마를 고르고 **X** (또는 −) → A. 쓰던 테마를 지우면 기본테마로 바뀝니다.
- **보기 탭**: 게임 목록에서 **ZL·ZR** 로 전체 · 즐겨찾기 · 최근 실행.
- **화면 효과**: 부드러운 목록 이동, 가로·세로 캐러셀 목록, 화면 전환(fade·slide), 배경 서서히 바뀜. Y 옵션 **"화면 효과"** 로 끌 수 있습니다.
- **나만의 카테고리** (`/JoyLauncher/categories.txt`): 카테고리 묶기(예: PlayStation = PS1+PS2+PSP)·넣고 빼기·숨기기(`[hide]`), 테마에 그림이 없을 때 모든 테마에서 쓰는 내 그림 폴더 `/JoyLauncher/categories/{backgrounds,logos,icons}/`. 적는 법: `테마_레이아웃.md` 12장
- **테마 확장 문법**: 칸 안 요소, 조건(`visible_if`·`hidden_if`), 자리표, `[strings]` 문구 바꾸기, ES-DE 기종 이름 자동 연결, 캐러셀. 이 문법을 쓴 테마는 **v1.1.0 이상**이 필요합니다(`requires = 1.1.0`). `테마_레이아웃.md` 11·12장

### 개선
- 큰 그림을 따로 읽어 들여(비동기) 그림이 많은 목록도 끊김 없이 스크롤됩니다.

> 자동 업데이트는 런처 본체만 바꿉니다. 테마는 업데이트한 뒤 **Y 옵션 → 테마 설정 → "기본 테마 4종 다시 받기"** 로 받으세요. (또는 릴리스 zip 의 `JoyLauncher/themes/` 복사)

> 테마 빌더 라이브러리의 Horizon·Iconic 그림은 CC BY-NC-SA 입니다. 이 그림을 쓴 테마를 나눌 때는 `library/<세트>/CREDITS-LICENSE.txt` 를 함께 넣어 주세요.

### English summary
- **Theme builder (PC)**: new **Joy Theme Builder** shows the Switch screen exactly as the launcher draws it. Windows 10/11 64-bit `JoyThemeBuilder_win64_1.1.0.zip` (`JoyThemeBuilder.exe`, demo `JoyDemo.exe`); Linux x86_64 `JoyThemeBuilder_linux_x86_64_1.1.0.tar.gz` (`./joythemebuilder`, needs `sudo apt install libsdl2-2.0-0 libsdl2-image-2.0-0 libsdl2-ttf-2.0-0`). Start wizard, element palette, design panel, image library with sets, custom categories editor, F5 demo window, gamepad support, send to Switch over FTP (sys-ftpd/ftpd or the launcher's own FTP screen) with list/delete of themes on the Switch, zip/folder export. Guide: `테마_빌더.md` (Korean)
- **Retro Game Gallery Theme** (`themes/DcGall`), the fourth bundled theme: gallery cards + a board table (number, title, views), white/navy design. Font Noto Sans KR (SIL OFL 1.1), icons from ES-DE Canvas (Siddy212, CC0); the "dcinside" text is a parody label, unrelated to DCinside. Needs launcher v1.1.0+
- Theme picker: the per-pack download rows are replaced by one row, **"Download the 4 stock themes"** ("... again" when all four are there), which downloads all four from the latest release in sequence (B cancels)
- **Receive themes from PC (FTP)**: in Y Options (below Theme) and as the last row of the theme picker. Shows `ftp://<Switch IP>:<port>` (usually 5000), anonymous, open only while the screen is shown; only `/JoyLauncher/themes/…`, `categories.txt` and `categories/…` can be written. B closes and reloads the themes
- **Delete themes**: select a theme in the picker, press **X** (or −), then A. Deleting the theme in use switches to Basic Theme
- **View tabs**: **ZL·ZR** in the game list switch between All · Favorites · Recently played
- **Screen effects**: smooth list movement, horizontal/vertical carousel lists, fade/slide transitions, background crossfade; turn them off with **"Screen effects"** in Y Options
- **Custom categories** (`/JoyLauncher/categories.txt`): combine (e.g. PlayStation = PS1+PS2+PSP), include/exclude and hide (`[hide]`) categories, plus your own pictures in `/JoyLauncher/categories/{backgrounds,logos,icons}/` used by any theme that lacks them
- **Theme extension syntax**: cell elements, conditions (`visible_if`/`hidden_if`), placeholders, `[strings]` text overrides, automatic ES-DE system names, carousel. Themes using it need v1.1.0+ (`requires = 1.1.0`). See `theme-layout-en.md` section 11
- Large pictures are loaded asynchronously, so lists with many pictures scroll smoothly
- The automatic update replaces only the launcher: get the themes from Y Options → Theme → "Download the 4 stock themes again" (or copy `JoyLauncher/themes/` from the release zip)
- Theme builder library: the Horizon and Iconic pictures are CC BY-NC-SA
