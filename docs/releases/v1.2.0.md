## Joy Launcher v1.2.0 (Nintendo Switch)

> **안드로이드판 Joy Launcher 1.2.0** 도 같은 날 나왔습니다 — 같은 테마를 그대로 씁니다. 릴리스 태그 `android-v1.2.0`, 소스는 `android` 브랜치.

### 새 기능
- **테마 BGM**: 테마 폴더 안에 `bgm` 폴더를 만들고 mp3·ogg 를 넣으면 그 테마의 배경 음악이 됩니다 (`theme.txt` 에 적을 것 없음). 테마를 바꾸면 그 테마의 곡으로 바뀝니다. 안드로이드판과 같은 규칙이라 BGM 이 든 테마를 서로 그대로 씁니다. 방법: `테마_만들기.md` 3번
- **BGM · 소리 설정**: Y 옵션의 BGM 항목이 소리 선택 창으로 바뀌었습니다 — **공통 BGM** (`/JoyLauncher/bgm`) / **테마 BGM** / **무음** 중 하나, 그리고 BGM 볼륨·순서·다음 곡. "BGM 켜짐/꺼짐" 항목은 없어졌고, 예전에 켜 두었던 설정은 공통 BGM 으로 넘어갑니다
- **버튼 그림**: 화면 아래 도움말의 [A] [B] [X] [Y] [L] [R] [ZL] [ZR] [+] [−] 를 스위치 버튼 모양 그림으로 그립니다 (끄기: 테마 `layout.txt` 의 `[theme] button_icons = off`)
- 기본 테마 4종에 **앱 즐겨찾기 그림**(`appfav`, 안드로이드판용) 추가 — 스위치판 화면에는 영향 없음

### 고친 것
- 레트로게임갤러리테마처럼 배경 색을 정한 테마에서 게임 목록을 빠르게 넘길 때 화면 사진 자리에 검은 네모가 깜빡이던 문제

> 자동 업데이트는 런처 본체만 바꿉니다. 새 그림이 든 테마는 **Y 옵션 → 테마 설정 → "기본 테마 4종 다시 받기"** 로 받으세요.

### English summary
- **Theme BGM**: put mp3/ogg files in a `bgm` folder inside a theme folder and they become that theme's background music (nothing to write in `theme.txt`); changing the theme changes the music. Same rule as the Android version, so themes with BGM are shared as they are. See `theme-guide-en.md` section 3
- **BGM / sound** window in Y Options: choose **Common BGM** (`/JoyLauncher/bgm`), **Theme BGM** or **Silent**, plus BGM volume, order and next song. The old "BGM On/Off" item is gone; an old "on" setting becomes Common BGM
- **Button icons**: [A] [B] [X] [Y] [L] [R] [ZL] [ZR] [+] [−] in the hint lines are drawn as Switch button shapes (turn off with `[theme] button_icons = off`)
- The four stock themes now include **App Favorites art** (`appfav`, used by the Android version)
- Fixed: black boxes flickering in the screenshot area when scrolling fast in themes with a background color (e.g. Retro Game Gallery Theme)
- **Joy Launcher for Android 1.2.0** is released the same day (tag `android-v1.2.0`, source on the `android` branch) and uses the same themes
