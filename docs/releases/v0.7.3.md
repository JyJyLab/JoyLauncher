## Joy Launcher v0.7.3

**0.7.1 · 0.7.2 를 쓰는 경우 꼭 업데이트하세요.**

### 수정
- **종료(+) 후 오류 화면, 런처에서 실행한 다른 홈브루(예: sphaira → ezRemote Client) 오류 수정.**
  업데이트 확인용 작업을 종료 시 정리하지 않아, 같은 실행 환경에서 다음에 실행되는 프로그램의 메모리가 깨지던 문제입니다.
  이제 종료하거나 게임·다른 프로그램을 실행하기 전에 업데이트 확인 작업과 네트워크 서비스를 정리합니다.
- **"원래 홈브루 메뉴로 되돌리기" 가 "sphaira 가 없어 되돌릴 수 없습니다" 로 실패하던 문제 수정** (기본 홈브루 메뉴로 실행 중일 때). 기본 메뉴로 설정할 때도 같은 처리.

### 업데이트 후
설치 후 바로 다시 시작되지만, 이전 버전에서 남은 메모리 문제를 깨끗이 없애려면 **HOME → 앱 닫기(X)** 또는 재부팅을 한 번 해 주세요.
