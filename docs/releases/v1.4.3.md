## Joy Launcher v1.4.3 (Nintendo Switch)

### 바뀐 것
- **목록 파일 밖의 롬도 보임**: 롬 폴더에 `gamelist.xml` · `metadata.pegasus.txt` 가 있어도, 목록에 없는 롬을 같은 카테고리에 함께 보여 줍니다 (ES-DE · Pegasus 와 같은 동작)
  - 목록에 없는 롬은 파일 이름이 제목으로 보입니다
  - gamelist.xml 에서 숨김(`hidden`) 으로 표시한 게임은 계속 숨깁니다
  - metadata.pegasus.txt 는 컬렉션에 `extensions:` 가 있을 때만 추가합니다. `ignore-files` · `ignore-extensions` 도 지킵니다
  - 롬 파일만 넣고 빼도 다음 실행 때 목록을 다시 읽습니다 (게임에서 돌아올 때는 지금처럼 확인을 건너뜀 — 옵션(Y) → «게임 목록 새로 고침»)
- **테마 그림 찾기를 안드로이드판과 같게**: "PS2 한글" 같은 폴더 이름도 그 기종 그림을, megadrivejp 같은 지역판 기종은 본래 기종 그림을 씁니다
- **테마 빌더 1.4.3**: 빌더로 만든 테마는 스위치 · 안드로이드 공통입니다
  - 위 줄 «미리보기»: 스위치 / 안드로이드 / 안드로이드 Xbox 패드 (X 버튼 이름 · 즐겨찾기 이름 · START·SELECT 표시만 바뀜, 테마 파일은 하나)
  - 테마 설정 창 «공통 점검»: 16:9 · 16:10 · 4:3 · 1:1 화면에서 화면 밖으로 나간 요소 등을 알려 줌
  - 테마 설정 창 «테마 BGM»: mp3 · ogg 곡 넣기 · 빼기

### English summary
- **ROMs outside the list files now show**: folders with `gamelist.xml` or `metadata.pegasus.txt` also list ROMs that are not in the file, in the same category (same as ES-DE and Pegasus). Unlisted ROMs use the file name as title; `hidden` games stay hidden; Pegasus collections add files only when they declare `extensions:` and respect `ignore-files` / `ignore-extensions`. Adding or removing ROM files is detected on the next start.
- **Theme art lookup matches the Android version**: folder names like "PS2 Korean" find the system art, regional systems (megadrivejp …) fall back to the base system art
- **Theme builder 1.4.3**: themes made with the builder work on both Switch and Android — preview as Switch / Android / Android with Xbox pad (labels only), «Common check» across 16:9 · 16:10 · 4:3 · 1:1, theme BGM add/remove
