## Joy Launcher v1.4.2 (Nintendo Switch)

### 바뀐 것
- **게임에서 돌아올 때 빠르게 시작**: 게임을 하고 런처로 돌아오면 롬 폴더 변경 확인을 건너뛰고 저장된 목록을 바로 씁니다 (실기 측정: 약 7초 → 약 1.4초, 롬·그림이 많을수록 차이가 큼)
  - 처음 켤 때와 홈브루(FTP 등)에서 돌아올 때는 지금처럼 확인합니다
  - 게임 중에 롬을 바꾼 경우에는 옵션(Y) → «게임 목록 새로 고침»

### English summary
- **Faster return from games**: after playing a game, the launcher skips the ROM folder change check and uses the saved list (measured: about 7 s → 1.4 s; bigger packs gain more). A normal check still runs on first start and when returning from other homebrew (FTP etc.); use Options (Y) → «Refresh game list» if you changed ROMs meanwhile.
