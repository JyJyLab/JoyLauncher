## Joy Launcher v1.3.1 (Nintendo Switch)

> 스위치판만의 작은 업데이트입니다. 안드로이드판은 `android-v1.3.0` 그대로입니다.

### 새 기능
- **X 버튼 끄기**: Y 옵션 → **X 버튼 (홈브루 메뉴 열기): 켜짐 / 꺼짐** (A 또는 ◀▶). 끄면 카테고리 · 게임 화면에서 X 를 눌러도 아무 일이 없고, 화면 아래 도움말에서 `[X] 홈브루` 가 빠집니다 (테마가 바꾼 문구도). 잘못 눌러 런처를 벗어나는 일을 막을 때 쓰세요
  - 테마 선택 창의 X (테마 지우기) 는 그대로입니다
  - 설정 파일: `settings.txt` 의 `x_button=on/off` (기본 on)

### English summary
- **Turn off the X button**: Y Options → **X button (open homebrew menu): On / Off** (A or ◀▶). When off, X does nothing on the category and game screens and `[X] Homebrew` disappears from the hint line (also a theme's own wording) — handy to avoid leaving the launcher by accident. X (delete) in the theme picker still works. Setting: `x_button=on/off` in `settings.txt` (default on)
- Switch only; the Android version stays at `android-v1.3.0`
