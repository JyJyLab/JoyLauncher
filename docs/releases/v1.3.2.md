## Joy Launcher v1.3.2 (Nintendo Switch)

> 스위치판 업데이트입니다. 안드로이드판은 `android-v1.3.1` 과 같은 옵션 분류를 씁니다.

### 바뀐 것
- **옵션 창 분류**: Y 옵션 맨 위 = **롬 및 홈브루 설정** ▶ · **테마 설정** ▶ · **시스템 설정** ▶ · 언어 · 업데이트 확인 · 종료 (HOME)
  - 롬 및 홈브루 설정: 게임 목록 새로 고침 · 영상 장면 일괄 추출 · **홈브루 즐겨찾기 목록 관리** · 실행: 홈브루 메뉴 / RetroArch / PPSSPP
  - 테마 설정: 테마 선택 · 화면 효과 · PC에서 테마 받기 (FTP)
  - 시스템 설정: BGM · 소리 설정 · X 버튼 (홈브루 메뉴 열기) · 기본 홈브루 메뉴 설정 / 되돌리기
  - 분류에서 A = 열기, B = 맨 위로, Y = 닫기. 분류에서 연 창(테마 선택 · 홈브루 즐겨찾기 · BGM)은 B 로 닫으면 그 분류로 돌아옵니다
  - 기본 홈브루 메뉴가 다른 메뉴로 바뀌었을 때의 «다시 설정» 줄은 예전처럼 맨 위에 나옵니다
- X 버튼(홈브루 메뉴 열기) · 설정 파일은 그대로입니다. 테마 문법 변화 없음

### English summary
- **Options are grouped**: **ROMs & homebrew** (refresh · extract video frames · Manage Homebrew Favorites · launch homebrew menu / RetroArch / PPSSPP) · **Theme settings** (choose theme · screen effects · receive themes from PC) · **System settings** (BGM / sound · X button · default homebrew menu) · Language · Check for updates · Exit (HOME)
- On a group A opens it, B goes back, Y closes; windows opened from a group return to it with B. "Set again" (when another menu took over) still appears at the very top
- X button, settings and theme syntax are unchanged
