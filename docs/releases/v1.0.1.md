## Joy Launcher v1.0.1

### 바뀐 점
- **테마 이름 변경**: 기본팩 → **기본테마**, 레트로팩 → **레트로테마**, 벽골김씨팩 → **벽골김씨테마** (영어 화면: Basic Theme / Retro Theme / WallStreetKim's Theme). 폴더 이름(`JoyBasic` · `RetroPack` · `ByeokgolKim`)은 그대로라 다시 설치할 필요는 없습니다. SD 카드에 예전 이름이 적힌 테마가 남아 있어도 테마 선택 창에는 새 이름으로 보입니다.
- **벽골김씨테마**: **즐겨찾기** · **홈브루 즐겨찾기** 카드 그림을 추가했습니다. (이전에는 그림 없이 이름 글자만 보였습니다)
- **벽골김씨테마**: **대전-아케이드** 카드가 NEO·GEO 그림으로 나오던 것을 다른 아케이드 카테고리와 같은 **아케이드** 그림으로 고쳤습니다.
- 영어 화면의 테마 선택 창: 긴 테마 이름이 잘리지 않도록 "Download … again (latest)" 를 "Download … again" 으로 줄였습니다.

> 자동 업데이트는 런처 본체만 바꿉니다. 벽골김씨테마의 새 카드 그림과 수정은 업데이트한 뒤 **Y 옵션 → 테마 설정 → "벽골김씨테마 다시 받기 (최신으로)"** 로 받으세요. (또는 릴리스 zip 의 `JoyLauncher/themes/` 복사)

### English summary
- **Theme names**: Basic Pack → **Basic Theme**, Retro Pack → **Retro Theme**, Byeokgol Kim Pack → **WallStreetKim's Theme** (Korean: 기본테마 / 레트로테마 / 벽골김씨테마). Folder names are unchanged, so nothing has to be reinstalled; themes on the SD card that still carry the old name are shown with the new one
- **WallStreetKim's Theme**: new cards for **Favorites** and **Homebrew Favorites** (they used to show only the name), and the fighting arcade category (대전-아케이드) now uses the arcade card instead of the NEO·GEO one
- English theme picker: "Download … again (latest)" shortened to "Download … again" so long theme names fit
- The automatic update replaces only the launcher: get the theme changes from Y Options → Theme → "Download WallStreetKim's Theme again" (or copy `JoyLauncher/themes/` from the release zip)
