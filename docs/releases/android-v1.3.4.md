## Joy Launcher for Android v1.3.4

스위치판과 테마를 함께 쓰는 Joy Launcher 의 안드로이드판입니다. 스위치판 릴리스는 태그 `v1.3.4`, 이 소스는 `android` 브랜치입니다. 버전 번호는 스위치판과 맞춥니다 (테마 `requires` 기준).

### 바뀐 것
- **스크롤바**: 넘치는 목록에 작은 스크롤바로 지금 위치를 보여 줍니다 — 게임·카테고리 목록(줄 · 격자 · 캐러셀)과 옵션 · 테마 선택 · 앱 목록 · 에뮬레이터 선택 · 롬 폴더 창. 테마에서 `scrollbar = auto / on / off`, `scrollbar_color`, `scrollbar_width`, `scrollbar_offset` 으로 바꿀 수 있습니다 (테마 문서 «목록»)
- **기본 테마 5종**: **아카이브플레이테마** 추가, **벽골김씨테마 V2** (검정 글자 · 굵은 글꼴 · 페이드 전환). 새로 설치하면 5종이 풀리고, 이미 쓰던 분은 테마 선택 창의 **"기본 테마 5종 다시 받기"** 로 받으세요

> **1.3.1 에서 올리기**: 이 페이지의 `JoyLauncher.apk` 를 받아 덮어 설치하면 `/JoyLauncher` 의 설정 · 테마 · 롬 폴더는 그대로입니다.

### English summary
- **Scroll bars**: lists that do not fit show a small scroll bar — game and category lists (text, grid, carousel) and the options, theme picker, app list, emulator picker and ROM folder windows. Themes can change it with `scrollbar = auto / on / off`, `scrollbar_color`, `scrollbar_width`, `scrollbar_offset`
- **5 stock themes**: new **Archive Play Theme** and **WallStreetKim's Theme V2** (black text, bold font, fade transitions). Fresh installs unpack all five; existing users can use "Download the 5 stock themes again" in the theme picker
- From 1.3.1: install `JoyLauncher.apk` over the old one — settings, themes and ROM folders stay
