## Joy Launcher v1.3.4 (Nintendo Switch)

> 안드로이드판도 같은 내용으로 `android-v1.3.4` 를 냅니다.

### 바뀐 것
- **스크롤바**: 넘치는 목록에 작은 스크롤바로 지금 위치(맨 위 · 맨 아래)를 보여 줍니다 — 게임 · 카테고리 목록(줄 · 격자 · 캐러셀)과 옵션 · 테마 선택 · 홈브루 즐겨찾기 창
- 테마에서 바꾸기 (목록 요소): `scrollbar = auto / on / off` (기본 auto = 넘칠 때만), `scrollbar_color` (기본 `color.scrollbar` → 없으면 dim), `scrollbar_width`, `scrollbar_offset`. 이 키를 쓰는 테마는 `requires = 1.3.4` (테마 빌더는 내보낼 때 자동)
- 테마 빌더 속성 창에 스크롤바 항목 4개

### English summary
- **Scroll bars**: lists that do not fit show a small scroll bar (top / bottom position) — game and category lists (text, grid, carousel) and the options, theme picker and homebrew favorites windows
- Theme keys on list elements: `scrollbar = auto / on / off` (default auto), `scrollbar_color` (default `color.scrollbar`, else dim), `scrollbar_width`, `scrollbar_offset`; themes using them need `requires = 1.3.4` (the theme builder adds it on export)
- Four scroll bar properties in the theme builder
