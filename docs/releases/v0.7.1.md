## Joy Launcher v0.7.1

깃헙 자동 업데이트를 처음 넣은 버전입니다.

### 새 기능
- **자동 업데이트**: 시작할 때 새 버전을 확인해 알려 주고, **Y 옵션 → 업데이트 설치** 로 내려받아 설치합니다. 받은 파일은 SHA-256 으로 검증한 뒤 교체하며, 기본 홈브루 메뉴(`/hbmenu.nro`)로 설정된 경우 함께 바뀝니다. 설치 후 자동으로 다시 시작합니다.
- 확인을 끄려면 `/JoyLauncher/settings.txt` 의 `auto_update=off`.

### 0.7.0 까지의 주요 기능
- X: 홈브루 메뉴, Y: 옵션 창 (RetroArch·PPSSPP·새로 고침·테마·영상 장면 일괄 추출·기본 메뉴 설정)
- 애플릿 모드 표시, 게임 목록 캐시, 실행 기록, cores.txt 코어 대체

### 설치
`JoyLauncher_0.7.1.zip` 의 `switch/` 를 SD 카드 루트에 복사. 자세한 내용은 zip 안의 `설명서.md`.
