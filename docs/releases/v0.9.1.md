## Joy Launcher v0.9.1

### 새 기능
- **NDS 게임을 DraStic 스위치판으로 실행**: `/switch/DrasticDS.nro`(DrasticDS_nx)가 있으면 NDS 카테고리가 보이고 그것으로 실행합니다.
  - `.nds`·`.zip`·`.rar` 를 실행하며, DrasticDS 가 열 수 없는 `.7z` 는 목록에서 숨깁니다.
  - 안드로이드 목록의 DraStic·melonDS 실행 설정도 DrasticDS 로 연결합니다.
  - 게임을 끝내면 DrasticDS 화면을 한 번 거쳐(거기서 종료) 런처로 돌아옵니다.
- **홈브루 즐겨찾기**: SD 카드에 넣은 nro 게임(포팅 게임 등)을 즐겨찾기처럼 모아 둘 수 있습니다.
  - **Y** 옵션 → **"홈브루 즐겨찾기 추가·빼기"** → SD 카드 `/switch` 의 nro 목록에서 **A** 또는 **−** 로 넣기(★)·빼기(☆).
  - 넣은 nro 가 있으면 카테고리 목록 맨 위(즐겨찾기 바로 아래)에 **"홈브루 즐겨찾기"** 가 생깁니다. 이름·아이콘은 nro 의 정보 그대로이고, 그 카테고리에서 **−** 를 누르면 뺍니다.
  - 목록은 `/JoyLauncher/homebrew_favorites.txt` 에 저장됩니다.

### 변경·수정
- **`cores.txt` 의 `[user]` 설정이 모든 게임에 적용됩니다.** 스위치용 목록(실행 설정이 스위치 코어 nro 인 팩)과 목록 없이 폴더로 인식한 게임에도 적용되고, 값에 코어 파일 이름 전체(`…_libretro_libnx.nro`)를 적어도 인식합니다. 적은 코어가 없으면 기본 코어로 실행하고, 실행 기록과 시작 알림으로 알려 줍니다. (예: `fbneo=fbalpha2012`)
- FB Alpha 2012: FBNeo 코어가 없으면 FB Alpha 2012 로 실행하고, 목록 없는 `fba2012`·`fbalpha2012` 폴더는 FB Alpha 2012 를 먼저 씁니다. ES-DE 목록의 `FB Alpha 2012`(CPS-1·CPS-2·CPS-3·Neo Geo 분리판 포함) 지정도 인식합니다.
- CPS2·CPS3 폴더가 PS2·PS3 제외 규칙에 걸려 목록에서 빠지던 문제를 고쳤습니다.
- 설명서: cores.txt 적용 범위와 예, DrasticDS, 홈브루 즐겨찾기를 추가했습니다.

### English summary
- NDS with the DraStic Switch port: when `/switch/DrasticDS.nro` (DrasticDS_nx) is installed, NDS games (`.nds`, `.zip`, `.rar`; `.7z` hidden) are shown and launched with it; Android DraStic/melonDS launch lines map to it. After a game you return through the DrasticDS screen
- Homebrew Favorites: Y Options → "Homebrew Favorites: add / remove" picks nro games (ports and other homebrew games) with A or −; they appear in a "Homebrew Favorites" category at the top, − removes them there. Saved in `/JoyLauncher/homebrew_favorites.txt`
- `[user]` in `cores.txt` now applies to every game (Switch-format lists, folder-detected games) and accepts full core file names; a missing core falls back to the default with a note in the launch log and a start-up notice (e.g. `fbneo=fbalpha2012`)
- FB Alpha 2012 as the FBNeo fallback and for `fba2012`/`fbalpha2012` folders; ES-DE `FB Alpha 2012` labels recognized
- Fixed CPS2/CPS3 folders being dropped by the PS2/PS3 exclusion rule
