## Joy Launcher v0.9.2

### 새 기능
- **오류 원인 확인용 동작 기록** `/JoyLauncher/debug_log.txt`: 다른 앱을 실행하거나 런처로 돌아올 때 오류로 꺼지는 경우의 원인을 찾기 위한 기록입니다.
  - 런처 시작(START)·앱 실행(LAUNCH)·종료(EXIT)·오류 종료(CRASH)를 남깁니다.
  - 앞에 실행한 앱이 남긴 스레드·메모리(«LEFTOVER»), 오류가 난 스레드·주소, Atmosphère 오류 기록(`/atmosphere/crash_reports`·`fatal_reports`·`erpt_reports`) 요약을 함께 적습니다.
  - 512 KB 가 넘으면 `debug_log_old.txt` 로 옮깁니다. 문제 신고 때 이 파일을 첨부해 주세요.
- **테마 추가·제작 설명서** (`테마_만들기.md`, 영어 `theme-guide-en.md`)를 릴리스 zip 에 넣었습니다. 직접 만든 배경·로고로 나만의 테마를 넣는 방법입니다.

### 수정
- `theme.txt` 의 줄 끝 설명(`snes=SFC   # 설명`)이 그림 이름에 섞여 연결이 안 되던 문제를 고쳤습니다. (`#`·`;` 앞에 공백이 있으면 설명으로 처리)
- `theme.txt` 의 `dim` 을 대문자(`DIM=`)로 적으면 무시되던 문제를 고쳤습니다.
- 테마 폴더 안내 파일(`/JoyLauncher/themes/README.txt`)의 `default.jpg` 설명이 실제 동작과 달랐던 것을 고쳤습니다. (`default.jpg` = "게임 목록이 없습니다" 화면 배경, 배경이 없는 카테고리는 테마를 끈 화면) 런처가 만든 옛 안내 파일은 자동으로 새 내용으로 바뀝니다. (직접 고친 파일은 그대로)
- 설명서: 테마 설명 바로잡기, 테마 설명서 링크, debug_log.txt 항목

> 테마는 자동 업데이트로 바뀌지 않습니다. 기본 테마 JoyBasic 은 그대로 써도 됩니다.

### English summary
- Diagnostic log `/JoyLauncher/debug_log.txt`: START / LAUNCH / EXIT / CRASH records, threads and memory left by the previous app ("LEFTOVER"), the crashing thread and address, and a summary of Atmosphère error reports; moved to `debug_log_old.txt` above 512 KB. Attach it to bug reports
- Theme guide for custom themes (`theme-guide-en.md`, Korean `테마_만들기.md`) in the release zip
- Fixed: a trailing comment in `theme.txt` (`snes=SFC   # note`) broke the mapping; `DIM=` in upper case was ignored
- Fixed: the theme folder guide `README.txt` described `default.jpg` wrongly (it is the "No games found" background; categories without a background use the no-theme look). Launcher-made old guides are updated automatically
