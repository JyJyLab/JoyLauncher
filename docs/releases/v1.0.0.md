## Joy Launcher v1.0.0

### 새 기능
- **테마로 화면 구성 바꾸기 (`layout.txt`)**: 테마 폴더에 `layout.txt` 를 넣으면 배경·로고뿐 아니라 화면 구성 자체를 바꿀 수 있습니다.
  - 카테고리 화면을 **기종 카드 격자**로, 게임 목록을 **박스 사진 격자**로 (▲▼◀▶ 로 이동)
  - 목록·사진·설명·제목·배터리·도움말의 **위치와 크기**, 숨기기
  - **글꼴**(ttf/otf), 글자 크기, **색**
  - 내 **그림**(판, 카드 바탕, 선택 테두리, 장식)과 **글자**(카테고리 이름, 게임 수, 시계 등)를 원하는 자리에 추가
  - 기종 아이콘 폴더(`icons/`), 카테고리 이름 바꾸기(`[names]`)
  - 잘못 적은 줄은 테마 폴더의 `layout_errors.txt` 에 알려 줍니다.
- **테마 팩 3종 포함**: **기본팩**(JoyBasic, 자체 제작) · **레트로팩**(기종별 게임기 사진 배경, 응애팩 테마 그림 발췌) · **벽골김씨팩**(기종 카드 격자 + 목록 판, 벽골김씨 님 구성 / ES-DE 테마 Canvas 바탕). 릴리스 zip 에 들어 있고, 테마 선택 창 아래쪽의 "<팩 이름> 내려받기" 로도 받을 수 있습니다.
- 테마 선택 창에 테마 이름 표시: `theme.txt` 의 `name=` (영어 화면 `name_en=`)
- 설명서: **테마 화면 구성 설명서** (`테마_레이아웃.md`, 영어 `theme-layout-en.md`) — 릴리스 zip 에 포함

`layout.txt` 가 없는 테마(JoyBasic 포함)와 테마를 끈 화면은 이전과 똑같습니다.

> 자동 업데이트는 런처 본체만 바꿉니다. 레트로팩·벽골김씨팩은 업데이트한 뒤 **Y 옵션 → 테마 설정 → "레트로팩 내려받기" / "벽골김씨팩 내려받기"** 로 받으세요. (또는 릴리스 zip 의 `JoyLauncher/themes/` 복사)

### 수정
- 읽을 수 없는 그림 파일(깨진 박스 사진 등)이 있으면 매 프레임 다시 읽으려 해 목록이 끊기고 다른 그림이 깜빡이던 문제를 고쳤습니다. (게임 목록 새로 고침 때 다시 읽음)

### English summary
- **Theme layouts (`layout.txt`)**: a theme can now change the screen layout — system card grid, box art grid, position/size/visibility of every element, fonts, colors, extra pictures and texts, an `icons/` folder and display names. Problems are reported in `layout_errors.txt` in the theme folder. Themes without `layout.txt` look exactly as before
- Three theme packs included: **Basic Pack** (JoyBasic, self-made), **Retro Pack** (console photo backgrounds, excerpt of the Eungae pack theme) and **Byeokgol Kim Pack** (card grid + list panel, arranged by Byeokgol Kim from the ES-DE theme Canvas); in the release zip and downloadable from the theme picker. Theme display names via `name=` / `name_en=` in `theme.txt`
- New guide: `theme-layout-en.md` (Korean `테마_레이아웃.md`), included in the release zip
- Fixed: an unreadable picture file was re-read every frame, causing stutter and flickering pictures
- The automatic update replaces only the launcher: after updating, get the new packs from Y Options → Theme → "Download Retro Pack" / "Download Byeokgol Kim Pack" (or copy `JoyLauncher/themes/` from the release zip)
