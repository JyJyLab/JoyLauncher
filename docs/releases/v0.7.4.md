## Joy Launcher v0.7.4

### 새 기능
- **영어 화면 지원**: 스위치 본체 언어를 따라 자동으로 한국어/영어. Y 옵션의 **"언어 / Language"** 에서 직접 고를 수 있습니다.
- **배경 음악(BGM)**: `/JoyLauncher/bgm/` 에 mp3·ogg 를 넣으면 Y 옵션 → **BGM 설정** 창에서 켜기/끄기, 볼륨, 순서(차례대로/무작위), 다음 곡을 고를 수 있습니다. 기본은 꺼짐이며, 런처에는 음악이 들어 있지 않습니다. 슬립·HOME 에서 돌아오면 서서히 커지며 이어서 재생합니다.
- **배터리 표시**: 오른쪽 위에 스위치 HOME 화면처럼 잔량과 전지 아이콘 (충전 중 초록·번개, 15% 이하 빨강).
- **긴 글자 가로 스크롤**: 다 안 들어가는 게임 이름·옵션·알림은 선택된 줄만 천천히 흘러가며 보여 주고, 나머지는 «…» 로 줄입니다.
- **긴 설명 세로 스크롤**: 게임 설명이 칸보다 길면 3초 뒤 천천히 위로 올라가며 끝까지 보여 줍니다. (전에는 일부가 잘림)
- **종료 확인**: 카테고리 화면에서 B 를 누르면 "런처를 종료합니다" 확인 창 (A 종료 / B 돌아가기).
- **무료 기본 테마 JoyBasic**: 자체 제작 배경·로고. zip 의 `JoyLauncher/` 를 SD 루트에 복사하면 처음 실행 때 자동 선택됩니다.
- 처음 실행할 때 `/JoyLauncher/themes/`, `/JoyLauncher/bgm/` 폴더와 안내 파일을 자동으로 만듭니다.
- 영어 설명서(`Manual_en.md`) 추가, 설명서 예시 화면을 JoyBasic 으로 교체.

### 수정
- 오른쪽 정보 칸 맨 위에 항상 게임 제목을 표시합니다. 다른 기종 게임을 섞은 카테고리([SMS]·[PSP] 등이 붙은 게임)에서 제목 대신 "SEGA · 1987 · 1인" 같은 제작사 줄만 보이던 문제 수정.

### English summary
- English interface (follows the system language; change it in Y Options → "Language / 언어")
- Background music from your own mp3/ogg files in `/JoyLauncher/bgm/` (off by default, no music included)
- HOME-style battery indicator, sideways scrolling for long text, upward scrolling for long descriptions
- Exit confirmation when pressing B on the category screen
- The info panel always shows the game title (fixes games that showed only "SEGA · 1987 · 1P")
- Free self-made default theme **JoyBasic** (copy `JoyLauncher/` from the zip to the SD root)
- English manual (`Manual_en.md`)
