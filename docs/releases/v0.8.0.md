## Joy Launcher v0.8.0

### 새 기능
- **즐겨찾기**: 게임 목록에서 **−** 버튼으로 넣기/빼기. 즐겨찾기한 게임은 이름 앞에 ★, 카테고리 목록 맨 위에 "즐겨찾기" 카테고리가 생깁니다. `/JoyLauncher/favorites.txt` 에 저장되어 게임 목록을 새로 고쳐도 유지됩니다.
- **BGM 표시 개선**: "켜짐 (On)" / "꺼짐 (Off)" 로 표시하고, 재생 중이면 초록색 글자로 보여 줍니다.
- 기본 테마 JoyBasic 에 즐겨찾기 배경·로고(`favorites`) 추가.

### 안내
- **롬 파일·폴더 이름은 영문(ASCII)을 권장합니다.** 한글 파일 이름은 목록에서 빠지거나 깨질 수 있습니다. 바꾸는 방법은 설명서 4번을 보세요.
- **테마는 자동 업데이트로 설치되지 않습니다.** 런처의 자동 업데이트는 `joylauncher.nro` 만 바꿉니다. 새 기본 테마(즐겨찾기 배경 포함)를 쓰려면 아래 `JoyLauncher_0.8.0.zip` 을 내려받아 `JoyLauncher/themes/` 를 SD 카드의 `/JoyLauncher/themes/` 에 복사하세요.

### English summary
- Favorites: press − in a game list to add/remove; ★ marks and a "Favorites" category at the top
- BGM labels show (On)/(Off), green while playing
- JoyBasic theme: new `favorites` background and logo
- Use ASCII names for ROM files and folders
- Themes are not installed by the automatic update — download the zip and copy `JoyLauncher/themes/` yourself
