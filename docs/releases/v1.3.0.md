## Joy Launcher v1.3.0 (Nintendo Switch)

> **안드로이드판 Joy Launcher 1.3.0** 도 같은 날 나왔습니다 — 같은 테마를 그대로 씁니다. 릴리스 태그 `android-v1.3.0`, 소스는 `android` 브랜치.

### 새 기능
- **메뉴 창이 테마 색으로**: 옵션 · BGM · 소리 설정 · 테마 선택 · 홈브루 즐겨찾기 · FTP · 종료 확인 · 진행 상자 · 알림 상자가 **둥근 모서리**로 바뀌고, 테마 색에 맞춘 판 · 테두리 · 글자로 그려집니다
  - 테마가 색을 정하지 않았으면 테마 색에서 알아서 맞춥니다 (비슷한 색의 테두리, 판과 잘 구분되는 글자, 보색 제목)
  - 테마를 쓰지 않을 때(기본)는 예전 색 그대로, 모서리만 둥글어집니다
  - 오류(빨강) · 완료(초록) 알림은 뜻을 지키려고 색은 그대로 둡니다
- 기본 테마 4종에 메뉴 색 지정: 기본테마(남색 · 노란 제목), 레트로테마(보라 테두리 · 호박색 제목), 벽골김씨테마(짙은 회색 · 흰 테두리), 레트로게임갤러리테마(흰 판 · 남색)
- **X 버튼 이름 통일**: 화면 아래 도움말이 `[X] 홈브루` 로 통일됩니다. 안드로이드판에서 만든 테마의 `[X] BGM` 도 스위치에서는 `홈브루` 로 보입니다 (테마가 정한 고유 이름은 그대로)
- **테마 만드는 분께**: `[theme]` 에 `color.menu`, `color.menu_border`, `color.menu_title`, `color.menu_text`, `color.menu_dim`, `color.menu_select`, `color.menu_select_text`, `menu_radius`, `menu_border_width` 추가 (설명: `테마_레이아웃.md` 12-1-2). 테마 빌더의 테마 설정 창에 "메뉴 창" 칸 추가
  - `color.menu…` 는 1.2.0 이하 런처에서도 문제없이 무시됩니다. `menu_radius` · `menu_border_width` 를 쓰면 `requires = 1.3.0` 을 적으세요 (빌더는 내보낼 때 알아서 적음)

> 자동 업데이트는 런처 본체만 바꿉니다. 메뉴 색이 든 기본 테마는 **Y 옵션 → 테마 설정 → "기본 테마 4종 다시 받기"** 로 받으세요 (안 받아도 테마 색에서 자동으로 맞춘 메뉴가 나옵니다).

### English summary
- **Menu windows follow the theme**: options, BGM / sound, theme picker, homebrew favorites, FTP, exit, progress and message boxes now have **rounded corners** and use panel / border / text colors matching the theme. Colors the theme does not set are derived from its colors (same-hue border, readable text, complementary title). With no theme the old colors stay and only the corners are rounded; error (red) / done (green) boxes keep their colors
- The four stock themes set their own menu colors
- **X button name**: the hint now reads `[X] Homebrew`; `[X] BGM` in themes made for the Android version shows as Homebrew on the Switch (a theme's own wording is kept)
- **For theme makers**: new `[theme]` keys `color.menu`, `color.menu_border`, `color.menu_title`, `color.menu_text`, `color.menu_dim`, `color.menu_select`, `color.menu_select_text`, `menu_radius`, `menu_border_width` (see `theme-layout-en.md`); a "Menu windows" section in the theme builder. `color.menu…` is ignored silently by 1.2.0 and older; add `requires = 1.3.0` if you use `menu_radius` / `menu_border_width` (the builder does it on export)
- Auto-update replaces only the launcher. Get the stock themes with menu colors from **Y Options → Theme → "Download the 4 stock themes again"**
- **Joy Launcher for Android 1.3.0** is released the same day (tag `android-v1.3.0`, source on the `android` branch) and uses the same themes
