## Joy Launcher v0.8.1

### 새 기능
- **기본 테마 JoyBasic 내려받기**: Y 옵션 → 테마 설정 창 맨 아래의 **"기본 테마 JoyBasic 내려받기"** (이미 있으면 "다시 받기 (최신으로)").
  - 깃헙 최신 릴리스에서 받아 크기·SHA-256 을 확인한 뒤 `/JoyLauncher/themes/JoyBasic/` 에 풉니다.
  - 기존 그림은 새것으로 바꾸고, 직접 넣은 그림은 그대로 둡니다. 진행 중 B 로 취소할 수 있습니다.
  - 이제 런처 자동 업데이트 후 테마도 이 메뉴로 최신으로 맞출 수 있습니다. (인터넷 연결 필요)
- 릴리스에 테마 전용 파일 `JoyBasic.zip` 을 함께 올립니다.

### 수정
- 테마 선택 창의 "사용 중" 표시가 보이지 않던 문제 (✓ 대신 "(사용 중)").

### English summary
- Download the default theme JoyBasic from the theme picker (Y Options → Theme → "Download default theme JoyBasic"), verified with SHA-256; your own images are kept
- New release asset `JoyBasic.zip`
- The "in use" mark in the theme picker is visible again
