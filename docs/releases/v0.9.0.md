## Joy Launcher v0.9.0

### 새 기능
- **ES-DE 설정 팩 지원**: 롬은 `/roms/<기종>/`, ES-DE 의 `gamelists`·`downloaded_media` 는 `/ES-DE/` 에 복사하면 게임 이름·설명·그림이 그대로 나옵니다.
  - 그림은 `downloaded_media` 의 covers·3dboxes·screenshots·titlescreens 등에서 찾고, 영상(videos)은 화면 사진이 없을 때 장면을 뽑는 데 씁니다.
  - 목록에 지정한 에뮬레이터(예: MAME 2003-Plus, PCSX ReARMed, PPSSPP)로 코어를 고릅니다.
  - 폴더마다 따로 판단하므로 페가수스 목록 폴더와 섞어 써도 됩니다. 페가수스 폴더의 그림 없는 게임도 ES-DE 그림으로 채웁니다.
  - ES-DE 폴더가 다른 곳에 있으면 `/JoyLauncher/roots.txt` 에 `esde=/경로/ES-DE`.
- **기본 홈브루 메뉴 처리 보강**
  - nx-hbmenu·sphaira 외의 메뉴도 `/switch/hbmenu_prev/<이름>.nro` 에 백업하고 되돌릴 수 있습니다.
  - Atmosphere 업데이트 등으로 `/hbmenu.nro` 가 다른 메뉴로 바뀌면 다음 실행 때 알리고, 옵션 맨 위에 **"Joy Launcher 를 기본 홈브루 메뉴로 다시 설정"** 을 보여 줍니다.
  - sphaira 의 자동 덮어쓰기(`replace_hbmenu`)는 sphaira 가 있으면 항상 끄고, sphaira 로 되돌릴 때만 원래 값으로 복원합니다.
  - X 버튼: 이전 기본 메뉴 → nx-hbmenu → sphaira 순서로 엽니다. 옵션 창에 설치·백업된 홈브루 메뉴를 이름·버전과 함께 모두 보여 줍니다.

### 변경
- **앨범(애플릿) 모드에서는 게임과 RetroArch·PPSSPP 를 실행하지 않고 경고만 띄웁니다.** 실기에서 PS1·PSP·FBNeo·GBA 모두 RetroArch 가 메모리 부족으로 오류가 났고, 끝낼 때 스위치 HOME 메뉴까지 오류(2144-0001)로 재부팅이 필요했습니다. 게임은 설치된 게임을 R 버튼을 누른 채 실행하는 등 타이틀 모드로 런처를 열어서 하세요.
- 알림 상자가 여러 줄을 한 번에 보여 줄 수 있게 바뀌었습니다.
- 설명서: 기종 범위를 "스위치에 RetroArch 코어(PSP 는 PPSSPP)가 있으면 표시 + 예외 2가지(기본 숨김, PS2 등 오인식 방지)"로 정리, 런처 실행 방법 표, ES-DE 사용법, Atmosphere 업데이트 후 대처를 추가했습니다.

### English summary
- ES-DE packs: copy ROMs to `/roms/<system>/` and ES-DE `gamelists` + `downloaded_media` to `/ES-DE/`; names, descriptions, images and the emulator chosen in the list are used. Can be mixed with Pegasus folders; `esde=` in `roots.txt` for another location
- Homebrew menu handling: any menu can be backed up and restored, a notice and "Set again" after an Atmosphere update replaces `/hbmenu.nro`, sphaira's auto-replace is kept off, X opens the previous menu → nx-hbmenu → sphaira
- Album (applet) mode no longer starts games or RetroArch/PPSSPP (they failed on hardware and crashed the HOME menu); open the launcher in title mode to play
- Multi-line notices; manual updates (display rule by RetroArch core, ES-DE, launch methods)
