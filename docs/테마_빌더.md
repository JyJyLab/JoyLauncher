# Joy Launcher 테마 빌더 (시험판)

PC 에서 **스위치 화면 그대로** 보며 테마를 만드는 프로그램입니다. 미리보기는 런처의 화면 그리기 코드를 그대로 써서, 스위치에서 보이는 모습과 같습니다.

[화면 구성 설명서](테마_레이아웃.md) · [테마 추가·제작 설명서](테마_만들기.md)

## 실행

| PC | 실행 파일 |
|---|---|
| 윈도우 10·11 (64비트) | `JoyThemeBuilder.exe` |
| 리눅스 (x86_64, SDL2 필요) | `joythemebuilder` (`sudo apt install libsdl2-2.0-0 libsdl2-image-2.0-0 libsdl2-ttf-2.0-0`) |

압축을 푼 폴더 그대로 실행합니다. 폴더 구성:

| 폴더 | 내용 |
|---|---|
| `work/themes/` | 만드는 테마 (자동 저장) |
| `templates/` | 새 테마의 시작 견본 (기본테마·레트로테마·벽골김씨테마·Horizon·Iconic·디시 갤러리) |
| `library/` | 그림 라이브러리 (배경·로고·아이콘·게임기 그림, 세트별) |
| `sample/roms/` | 미리보기용 가짜 롬 폴더 (27기종) |
| `romfs/` | 내장 글꼴 |

## 화면

| 자리 | 내용 |
|---|---|
| 왼쪽 **레이어** | 화면의 요소 목록 (위가 앞). 눈(체크)으로 보이기·숨기기, 누르면 선택. 목록 아래 `└` 는 칸 안 요소 |
| 가운데 **화면** | 스위치 화면 미리보기. 누르기 = 선택, 끌기 = 이동, 노란 손잡이 = 크기, 방향키 1점·Shift+방향키 10점, Alt+누르기 = 겹친 아래 요소, Del = 삭제 |
| 화면 위 줄 | 미리볼 카테고리·게임, ◀▲▼▶ L R (런처 조작과 같음), ★ 즐겨찾기 토글, 영어 화면 |
| 오른쪽 **속성** | 고른 요소의 속성. 노란 이름 = layout.txt 에 적힌 값, `x` = 기본값으로 |
| 아래 **도구** | 그림 · 테마 설정 · 문구 · 카테고리 이름 · 기종 연결 · layout.txt(직접 편집) · 문제 · 미리보기 자료 |

## 만들기 순서

1. **파일 → 새 테마** — 폴더 이름(영문)과 시작 견본을 고름. "주요 기종 그림만"이면 스위치 런처에서 쓰는 35개 기종만 채워 용량을 줄임
2. **그림** 탭 — 기종마다 라이브러리 세트의 그림을 눌러 넣거나 `파일...` 로 내 그림을 넣음. 세트를 골라 **이 세트로 전부 채우기 / 없는 것만 채우기**. 넣을 때 알맞은 크기로 줄여 저장 (배경 1280x720, 로고 640x200, 아이콘 512)
3. **화면**에서 요소를 옮기고 크기를 바꾸고, **속성**에서 글꼴·색·자리표를 고침. 왼쪽 위 **추가: 글자 / 그림 / 네모**
4. 목록을 고르면 속성 맨 아래 **+ 칸 글자 / + 칸 그림 / + 칸 네모** — 칸마다 반복되는 요소 (게시판 번호·조회수, 카드 안 여러 줄 글자)
5. **테마 설정** — 테마 이름, 글꼴(라이브러리·가져오기), 기본 색, 내 색 이름
6. **문구** — 조작 도움말 등 화면 문구 바꾸기
7. **파일 → 내보내기** — zip(게시판 배포용) 또는 폴더 복사(SD 카드의 `/JoyLauncher/themes` 를 고르면 바로 스위치용)

- 바꿀 때마다 `work/themes/<테마>/` 에 자동 저장. **Ctrl+Z / Ctrl+Y** 실행 취소·다시 실행, **Ctrl+D** 복제
- 그림·글꼴 파일을 창에 끌어 놓기: 그림 → 새 그림 요소, ttf·otf → 테마 글꼴
- 다른 곳의 테마 폴더는 **파일 → 열기 → 다른 곳의 테마 폴더 가져오기** (그 폴더의 theme.txt 를 고름)
- **미리보기 자료** 탭에서 SD 카드의 `/roms` 를 고르면 내 롬 모음으로 미리볼 수 있음
