# Joy Launcher 테마 빌더 (시험판)

PC 에서 **스위치 화면 그대로** 보며 테마를 만드는 프로그램입니다. 미리보기는 런처의 화면 그리기 코드를 그대로 써서, 스위치에서 보이는 모습과 같습니다.

[화면 구성 설명서](테마_레이아웃.md) · [테마 추가·제작 설명서](테마_만들기.md)

## 실행

| PC | 실행 파일 |
|---|---|
| 윈도우 10·11 (64비트) | `JoyThemeBuilder.exe` (데모 창은 `JoyDemo.exe`) |
| 리눅스 (x86_64, SDL2 필요) | `joythemebuilder` (`sudo apt install libsdl2-2.0-0 libsdl2-image-2.0-0 libsdl2-ttf-2.0-0`) |

압축을 푼 폴더 그대로 실행합니다. 폴더 구성:

| 폴더 | 내용 |
|---|---|
| `work/themes/` | 만드는 테마 (자동 저장) |
| `work/categories.txt`, `work/categories/` | 나만의 카테고리·내 그림 폴더 (스위치의 /JoyLauncher 와 같은 구성) |
| `templates/` | 새 테마의 시작 견본 (기본테마·레트로테마·벽골김씨테마·Horizon·Iconic·디시 갤러리·조이 캐러셀·조이 휠) |
| `library/` | 그림 라이브러리 (배경·로고·아이콘·게임기 그림, 세트별) |
| `sample/roms/` | 미리보기용 가짜 롬 폴더 (27기종) |
| `romfs/` | 내장 글꼴 |

## 시작 마법사

빌더를 켜면 (또는 **파일 → 새 테마**):

1. **테마 스타일 고르기** — 기본 목록 · 가로 캐러셀 · 세로 휠 · 카드 격자 · 게시판 · 레트로 · Horizon · Iconic 카드 (미리보기·설명). 아래 **기존 테마 이어서 편집** 으로 만들던 테마 열기
2. **시작 방법 고르기**
   - **자동 매칭** — 고른 스타일 구성 그대로, 롬 폴더의 카테고리에 맞는 배경·로고·아이콘을 라이브러리에서 자동으로 넣음 (예: 'FC' → nes 그림, 'PS1' → psx 그림)
   - **완전 빈 테마** — 그림·요소 없는 빈 화면. 스타일의 글꼴·색만 가져옴. 왼쪽 **요소 넣기** 로 하나씩 넣어 꾸밈

## 요소 넣기와 디자인

- 왼쪽 **요소 넣기**: 배경(배경 그림·막대) · 목록(줄 목록·카드 격자·가로 캐러셀·세로 휠 / 게임 화면은 박스 격자·박스 캐러셀·제목 휠) · 기종(카테고리 이름·게임 수·기종 그림·로고·박스 미리보기) · 게임(화면 사진·정보·제목·제작사·설명·보기 탭·쪽 표시·실행 기록) · 기타(배터리·시계·도움말·글자·그림·네모). 버튼에 마우스를 올리면 설명
- 그림을 쓰는 요소를 넣었는데 테마에 그 그림이 없으면 아래 [그림] 탭이 열림 → 세트를 골라 **이 세트로 전부 채우기**
- 요소를 고르면 오른쪽 **디자인** 항목이 켜짐 (안 고르면 흐리게)
  - 글자: 크기(작게·보통·크게·제목), 굵기, 정렬, 색, 내용(자리표)
  - 목록: 모양(줄·격자·가로 캐러셀·세로 휠), 칸 그림, 움직임(바로·부드럽게·느긋하게), 선택 표시 색, 글자 색·크기
  - 그림: 출처(배경·로고·아이콘·박스·화면·내 파일), 맞추기, 불투명도, 어둡게
  - 네모·배터리 등: 색
  - **세부 속성** 을 펼치면 layout.txt 의 모든 항목

## 데모 실행 (F5)

메뉴 줄의 **▶ 데모 실행** (또는 F5): 지금 테마를 **실제 런처 그대로** 새 창에서 조작 (움직임·화면 전환·보기 탭·즐겨찾기 포함, 게임 실행 대신 알림).

| 키 | 스위치 버튼 |
|---|---|
| Enter · Space | A |
| Esc · Backspace | B |
| 방향키 | 방향 |
| Q / W | L / R |
| Z / X | ZL / ZR |
| F | − (즐겨찾기) |
| T / Y | X / Y |

## 패드로 조작

PC 에 패드(엑스박스·플레이스테이션·스위치 프로 콘트롤러 등)를 연결하면 빌더의 미리보기와 데모 창을 스위치처럼 조작합니다 (윈도우·리눅스 공통).

| 패드 | 동작 |
|---|---|
| 십자키 · 왼쪽 스틱 | 이동 (누르고 있으면 반복) |
| A / B | 열기 / 뒤로 (스위치 프로 콘트롤러는 글자 위치 그대로) |
| L / R | 카테고리 이동 |
| ZL / ZR | 보기 탭 |
| − (Back·Select) | 즐겨찾기 |
| X · Y · + | 데모 창에서 홈브루·옵션·종료 (빌더 미리보기에서는 쓰지 않음) |

## 화면

| 자리 | 내용 |
|---|---|
| 왼쪽 **레이어** | 화면의 요소 목록 (위가 앞). 눈(체크)으로 보이기·숨기기, 누르면 선택. 목록 아래 `└` 는 칸 안 요소 |
| 가운데 **화면** | 스위치 화면 미리보기. 누르기 = 선택, 끌기 = 이동, 노란 손잡이 = 크기, 방향키 1점·Shift+방향키 10점, Alt+누르기 = 겹친 아래 요소, Del = 삭제 |
| 화면 위 줄 | 미리볼 카테고리·게임, ◀▲▼▶ L R ZL ZR A B (런처 조작과 같음, 움직임·화면 전환이 그대로 보임), ★ 즐겨찾기 토글, 영어 화면 |
| 오른쪽 **속성** | 고른 요소의 속성. 노란 이름 = layout.txt 에 적힌 값, `x` = 기본값으로 |
| 아래 **도구** | 그림 · 테마 설정 · 문구 · 나만의 카테고리 · 카테고리 이름 · 기종 연결 · layout.txt(직접 편집) · 문제 · 미리보기 자료 |

## 만들기 순서

1. **파일 → 새 테마** — 폴더 이름(영문)과 시작 견본을 고름. "주요 기종 그림만"이면 스위치 런처에서 쓰는 35개 기종만 채워 용량을 줄임
2. **그림** 탭 — 기종마다 라이브러리 세트의 그림을 눌러 넣거나 `파일...` 로 내 그림을 넣음. 세트를 골라 **이 세트로 전부 채우기 / 없는 것만 채우기**. 넣을 때 알맞은 크기로 줄여 저장 (배경 1280x720, 로고 640x200, 아이콘 512)
3. **화면**에서 요소를 옮기고 크기를 바꾸고, **속성**에서 글꼴·색·자리표를 고침. 왼쪽 위 **추가: 글자 / 그림 / 네모**
4. 목록을 고르면 속성 맨 아래 **+ 칸 글자 / + 칸 그림 / + 칸 네모** — 칸마다 반복되는 요소 (게시판 번호·조회수, 카드 안 여러 줄 글자)
5. **테마 설정** — 테마 이름, 글꼴(라이브러리·가져오기), 기본 색, 내 색 이름
6. **문구** — 조작 도움말 등 화면 문구 바꾸기
7. **나만의 카테고리** — 여러 카테고리를 묶은 내 카테고리 (예: PlayStation = PS1+PS2+PSP), 숨길 카테고리. 그림은 [그림] 탭에서 **내 그림 폴더**를 고르고 넣으면 모든 테마에서 쓰임
8. **테마 설정 → 화면 효과** — 움직임 시간, 배경 서서히, 화면 전환(fade·slide). 목록 속성의 "목록 모양 = carousel" 로 캐러셀
9. **파일 → 스위치로 보내기 (FTP)** — 스위치 ftpd(sys-ftpd) 주소·포트를 적고 보내기. 테마 폴더만 /JoyLauncher/themes/<테마> 로, 바뀐 파일만. "내 카테고리도" 를 켜면 categories.txt·내 그림 폴더도
10. **파일 → 내보내기** — zip(게시판 배포용) 또는 폴더 복사(SD 카드의 `/JoyLauncher/themes` 를 고르면 바로 스위치용)

- **파일 → 테마 관리 (지우기)** — 만든 테마 목록·용량, 열기·지우기 (함께 든 견본은 잠금). 새 테마 이름이 겹치면 "기존 테마 지우고 새로 만들기" 도 가능
- 스위치에서는 테마 선택 창(Y 옵션 → 테마 설정)에서 테마를 고르고 **[X]** → [A] 로 지움 (쓰던 테마를 지우면 기본테마로)
- 바꿀 때마다 `work/themes/<테마>/` 에 자동 저장. **Ctrl+Z / Ctrl+Y** 실행 취소·다시 실행, **Ctrl+D** 복제
- 그림·글꼴 파일을 창에 끌어 놓기: 그림 → 새 그림 요소, ttf·otf → 테마 글꼴
- 다른 곳의 테마 폴더는 **파일 → 열기 → 다른 곳의 테마 폴더 가져오기** (그 폴더의 theme.txt 를 고름)
- **미리보기 자료** 탭에서 SD 카드의 `/roms` 를 고르면 내 롬 모음으로 미리볼 수 있음
