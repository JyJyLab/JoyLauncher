# Joy Launcher 테마 추가·제작 설명서

[설명서로 돌아가기](설명서.md)

테마는 카테고리(기종)마다 **배경 그림**과 게임 목록 위쪽의 **로고**를 바꿔 주는 그림 모음입니다.
SD 카드의 `/JoyLauncher/themes/` 안에 폴더 하나를 넣으면 테마 하나가 추가됩니다. 프로그램을 고치거나 다시 설치할 필요가 없습니다.

> **화면 구성까지 바꾸려면** (카테고리 카드 격자, 목록·사진 위치, 글꼴·색, 내 그림 추가): **[테마 화면 구성 설명서 (layout.txt)](테마_레이아웃.md)** — v1.0.0 부터

---

## 1. 테마가 바꾸는 곳

| 화면 | 바뀌는 것 |
|---|---|
| 카테고리 화면 | 커서가 있는 카테고리의 **배경**. 커서를 옮기면 배경도 따라 바뀝니다. 제목은 "Joy Launcher" 글자 그대로 |
| 게임 목록 화면 | 그 카테고리의 **배경** + 제목 글자 대신 **로고** (로고 그림이 있을 때만) |
| "게임 목록이 없습니다" 화면 | `default` 배경 |

- 배경이 깔리면 위·아래 막대와 선택 표시가 반투명으로 바뀌어 배경이 비쳐 보입니다.
- 배경 그림이 없는 카테고리는 테마를 끈 화면(어두운 단색)으로 보입니다. `default` 배경이 대신 나오지 않습니다.

## 2. 빠르게 만들기 (5단계)

1. PC 에서 영문 이름의 폴더를 만듭니다. 예) `MyTheme`
2. 그 안에 `backgrounds` 폴더를 만들고, **롬 폴더 이름과 같은 이름**으로 배경 그림을 넣습니다.
   예) `/roms/GBA` → `backgrounds/GBA.jpg`, `/roms/snes` → `backgrounds/snes.jpg`
3. (선택) `logos` 폴더에 같은 이름의 투명 PNG 로고를 넣습니다. 예) `logos/GBA.png`
4. (선택) `theme.txt` 를 만들어 어둡기와 이름 연결을 적습니다. (6번)
5. `MyTheme` 폴더째 SD 카드의 `/JoyLauncher/themes/` 에 복사하고, 런처에서 **Y 옵션 → 테마 설정 → MyTheme → A** 를 누릅니다.

## 3. 폴더 구조

```
/JoyLauncher/themes/
├─ JoyBasic/                 기본테마 (RetroPack = 레트로테마, ByeokgolKim = 벽골김씨테마, DcGall = 레트로게임갤러리테마, ArchivePlay = 아카이브플레이테마)
└─ MyTheme/                  새 테마 (폴더 이름 = 테마 선택 창에 보이는 이름)
   ├─ backgrounds/
   │  ├─ GBA.jpg             카테고리 배경
   │  ├─ SFC.png
   │  ├─ favorites.jpg       즐겨찾기 카테고리 배경
   │  └─ default.jpg         "게임 목록이 없습니다" 화면 배경 (선택)
   ├─ logos/                 (선택)
   │  ├─ GBA.png             게임 목록 제목 대신 보일 로고
   │  └─ SFC.png
   ├─ bgm/                   (선택) 테마 BGM — v1.2.0 부터
   │  ├─ 01.mp3              mp3·ogg, 이름순(또는 무작위)으로 재생
   │  └─ 02.ogg
   └─ theme.txt              (선택) 어둡기·이름 연결
```

- `backgrounds` 와 `logos` 바로 안의 파일만 읽습니다. 그 안에 하위 폴더를 만들면 읽지 않습니다.
- 확장자는 `.jpg`, `.jpeg`, `.png` 만 인식합니다. (대소문자 무관)
- `backgrounds` 만 있어도, `logos` 만 있어도 됩니다. 둘 다 비어 있으면 테마를 골라도 아무것도 바뀌지 않습니다.

### 테마 BGM (v1.2.0 부터)
테마 폴더 안에 `bgm` 폴더를 만들고 **mp3 또는 ogg** 파일을 넣으면 그 테마의 BGM 이 됩니다. `theme.txt` 에 적을 것은 없습니다.
- 런처의 **BGM · 소리 설정**(옵션 창, 안드로이드판은 X 버튼)에서 **테마 BGM** 을 고르면, 이 테마를 쓰는 동안 이 폴더의 곡이 재생됩니다. 테마를 바꾸면 그 테마의 곡으로 바뀌고, `bgm` 폴더가 없는 테마에서는 소리가 나지 않습니다.
- **공통 BGM** 을 고르면 테마와 상관없이 `/JoyLauncher/bgm` 의 곡이 재생됩니다. 볼륨·순서는 런처 설정을 따릅니다.
- 스위치판·안드로이드판 모두 같은 방식이라 BGM 이 든 테마를 서로 그대로 씁니다. v1.1 이하의 런처는 `bgm` 폴더를 무시합니다.
- 파일 이름은 영문(ASCII)을 권장합니다. 테마를 배포할 때는 곡의 저작권을 확인하세요 (11번).

## 4. 그림 규격

### 배경

| 항목 | 권장 |
|---|---|
| 크기 | **1280 × 720** (16:9). 스위치 화면 크기 그대로 |
| 형식 | JPG (용량이 작아 빨리 뜸). 투명이 필요 없으면 PNG 보다 JPG |
| 용량 | 한 장 500 KB 이하 권장 |

- 비율이 16:9 가 아니면 **비율을 유지한 채 화면을 가득 채우고, 넘치는 부분은 가운데 기준으로 잘라 냅니다.** 중요한 그림은 가운데에 두세요.
- 배경 위에 게임 목록 글자가 올라갑니다. 왼쪽(목록)과 오른쪽(박스·화면 사진)이 모두 쓰이므로 너무 밝거나 복잡한 그림은 `dim` 으로 어둡게 하세요.
- 카테고리를 빠르게 넘기는 동안에는 새 배경을 읽지 않고, 커서가 멈추면(약 0.15초) 읽습니다. 그림이 크면 뜨는 데 시간이 더 걸립니다.

### 로고

| 항목 | 권장 |
|---|---|
| 형식 | **투명 배경 PNG** |
| 표시 영역 | 화면 위쪽 가운데 **440 × 60** 칸 |
| 크기 | 가로:세로 약 7:1 이 칸을 꽉 채움. 예) 880 × 120 |

- 로고는 비율을 유지한 채 440 × 60 칸 안에 맞춰 줄여서 보입니다. 세로가 긴 로고는 작게 보입니다.
- 로고가 없는 카테고리는 카테고리 이름 글자가 그대로 보입니다.

### 어둡기 (dim)

배경 위에 검은 막을 덮는 정도입니다. `theme.txt` 에 `dim=0~255` 로 적습니다.

| 값 | 결과 |
|---|---|
| `0` | 그림 그대로 |
| `40` | 살짝 어둡게 (JoyBasic 의 값) |
| `150` | 꽤 어둡게 (**`theme.txt` 가 없거나 `dim` 을 안 적었을 때 기본값**) |
| `255` | 완전히 검게 |

## 5. 그림 이름 정하기 — 런처가 그림을 찾는 순서

카테고리마다 아래 순서로 찾아 **처음 찾은 그림**을 씁니다. 배경과 로고를 각각 따로 찾습니다.

1. `theme.txt` 에 **카테고리 이름**(또는 `shortname`)으로 연결한 그림 — 항상 가장 우선
2. 롬 폴더가 하나인 카테고리: **롬 폴더 이름**으로 연결한 그림, 없으면 롬 폴더 이름과 같은 파일
3. 카테고리 `shortname` 또는 **카테고리 이름**과 같은 파일
4. 여러 롬 폴더를 합친 카테고리: 그림이 있는 첫 롬 폴더의 그림 (연결 → 같은 이름 파일 순)

규칙:

- **영문 대소문자는 구분하지 않습니다.** `GBA.jpg` = `gba.jpg`
- 그 밖에는 **글자 하나까지 같아야** 합니다. 띄어쓰기·괄호·하이픈도 그대로입니다. (`FC hack` ≠ `FC_hack`)
- **롬 폴더 이름**은 롬 파일이 **바로 들어 있는** 폴더의 이름입니다. `/roms/GBA/hack/a.gba` 라면 `hack` 입니다.
- **카테고리 이름**은
  - 페가수스 목록이 있으면 `metadata.pegasus.txt` 의 `collection:` 값
  - 목록 없이 런처가 폴더로 기종을 추정했으면 아래 표의 **한글 이름** (영어 화면에서도 이 이름으로 찾습니다)
  - `shortname:` 줄이 있으면 그 값도 함께 씁니다.

### 특별한 이름

| 그림 이름 | 쓰이는 곳 |
|---|---|
| `favorites` | 즐겨찾기 카테고리 (게임에서 − 버튼으로 추가) |
| `hbfav` | 홈브루 즐겨찾기 카테고리 |
| `default` (또는 `main`, `all`) | "게임 목록이 없습니다" 화면 |

## 6. theme.txt 쓰기

```ini
# 설명 줄은 #, ; 또는 [ 로 시작합니다
dim=60

[카테고리 이름 → 그림]
# backgrounds/arcade_action.jpg, logos/arcade_action.png
액션-아케이드=arcade_action
# 여러 폴더를 합친 카테고리
Play Station=PS1
# 즐겨찾기에 favorites 대신 star 그림
즐겨찾기=star

[롬 폴더 이름 → 그림]
# /roms/snes → backgrounds/SFC.jpg
snes=SFC
genesis=MD
```

- 형식: `<카테고리 또는 롬 폴더 이름>=<그림 파일 이름>`
- 그림 파일 이름은 `backgrounds/`·`logos/` 안의 이름입니다. **확장자는 빼도, 적어도 됩니다.** (`SFC` = `SFC.jpg`)
- 한 줄로 **배경과 로고가 함께** 연결됩니다. 로고 그림이 없으면 배경만 바뀝니다.
- 연결한 그림 파일이 없으면 그 줄은 무시하고 다음 순서(5번)로 찾습니다.
- `=` 앞뒤 공백, 줄 끝 공백은 무시합니다.
- 줄 끝에 설명을 붙일 수 있습니다: `snes=SFC   # 슈퍼패미컴` (`#` 또는 `;` **앞에 공백**이 있어야 함). 단 **v0.9.1 이하**는 줄 끝 설명을 그림 이름으로 읽어 연결이 안 되므로, 옛 버전에서도 쓸 테마라면 설명을 별도 줄에 쓰세요.
- `dim` 은 대소문자 무관(`DIM=60` 도 됨)
- 인코딩은 **UTF-8** 로 저장하세요. (윈도우 메모장: "다른 이름으로 저장 → 인코딩 UTF-8". BOM 이 있어도 됩니다)
- 같은 이름을 두 번 적으면 아래 줄이 적용됩니다.

> **한글 카테고리는 theme.txt 로 연결하세요.** 한글 이름의 그림 파일은 스위치 FTP 로 복사할 때 만들어지지 않는 경우가 있습니다. 그림 파일은 영문으로 두고 `한글 카테고리=영문그림` 으로 적는 것이 안전합니다.

## 7. SD 카드에 넣고 적용하기

1. 테마 폴더째 `/JoyLauncher/themes/` 에 복사 (카드 리더 또는 FTP)
   - **폴더·파일 이름은 영문·숫자로** 만드세요.
2. 런처에서 **Y 옵션 → 테마 설정** — 새 폴더가 목록에 바로 보입니다. (이름순)
3. 테마를 고르고 **A**. 고른 테마는 `settings.txt` 의 `theme=` 에 저장되어 다음 실행에도 유지됩니다.
4. **"기본 (배경 없음)"** 을 고르면 테마를 끕니다.

### 그림을 고치거나 추가했을 때

런처는 테마를 고르는 순간 그림 목록을 읽어 둡니다. 런처를 켠 채로 그림을 추가·교체했다면 **테마 설정에서 같은 테마를 다시 골라 A** 를 누르세요. (런처를 다시 시작해도 됩니다)

## 8. 페가수스 테마 그림 그대로 쓰기

페가수스 테마의 그림 폴더를 테마 폴더에 그대로 넣어도 읽습니다.

| 런처가 읽는 폴더 | 용도 |
|---|---|
| `backgrounds/`, `Background_image1/`, `Resource/Background_image1/` | 배경 |
| `logos/`, `Logo1/`, `Resource/Logo1/` | 로고 |

같은 이름의 그림이 여러 폴더에 있으면 위 표의 왼쪽 폴더가 우선입니다. 그림 이름이 카테고리·롬 폴더 이름과 다르면 `theme.txt` 로 연결하세요.

## 9. 함께 들어 있는 팩 고쳐 쓰기, 이름 붙이기

- 기본테마(`JoyBasic`)·레트로테마(`RetroPack`)·벽골김씨테마(`ByeokgolKim`)·레트로게임갤러리테마(`DcGall`)·아카이브플레이테마(`ArchivePlay`)는 테마 설정의 **"기본 테마 5종 다시 받기"** 를 누르면 5종 모두 같은 이름의 그림이 새것으로 바뀝니다. (직접 추가한 그림은 남음)
- 그림을 고쳐 쓰려면 **폴더를 다른 이름(예: `JoyBasicMy`)으로 복사**한 뒤 고치세요.
- 테마 선택 창에 보일 이름은 `theme.txt` 에 `name=내 테마` (영어 화면용 `name_en=My Theme`) 로 정합니다. 안 적으면 폴더 이름이 보입니다. (v1.0.0 부터)
- JoyBasic 그림은 저장소의 `tools/make_joybasic.py` (Python + Pillow) 로 다시 만들 수 있습니다. 색·글자를 바꿔 새 테마를 만들 때 참고하세요.

## 10. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| 테마 선택 창에 폴더가 안 보임 | 위치가 `/JoyLauncher/themes/<폴더>/` 인지 (한 단계 더 들어가 있지 않은지), 폴더 이름이 `.` 으로 시작하지 않는지 |
| 테마를 골라도 아무것도 안 바뀜 | `backgrounds/`·`logos/` 폴더 이름 철자, 확장자(jpg·jpeg·png) |
| 특정 카테고리만 배경이 없음 | 그림 이름이 롬 폴더 이름·카테고리 이름과 글자까지 같은지 (5번). 다르면 `theme.txt` 로 연결 |
| 다른 그림이 나옴 | 5번 순서상 앞선 연결이 있는지. `theme.txt` 에 카테고리 이름으로 직접 지정 |
| 한글 카테고리 연결이 안 됨 | `theme.txt` 가 UTF-8 인지, 카테고리 이름이 화면(한국어 설정)에 보이는 이름과 같은지 |
| 그림을 바꿨는데 예전 그림이 나옴 | 테마를 다시 골라 A (7번) |
| 배경이 늦게 뜸 | 그림 크기를 1280 × 720 JPG 로 줄이기 |
| 글자가 잘 안 보임 | `dim` 값을 올리기 |

## 11. 저작권

회사 로고, 게임 화면, 남이 만든 테마 그림은 개인적으로 쓰는 것은 괜찮아도 **배포하면 저작권 문제가 될 수 있습니다.** 테마를 공유하려면 직접 만든 그림이나 사용이 허락된 그림만 쓰세요.
